# Lerium Group · Web corporativa

Sitio web estático construido con HTML, [Tailwind CSS](https://tailwindcss.com) (vía CDN) y JavaScript vanilla.

## Estado

Actualmente se sirve una landing de **"en construcción"** (`index.html`).

## Estructura

```
index.html     Landing principal ("en construcción")
js/main.js     Scripts de la web
assets/        Logo y favicon oficiales de Lerium
```

## Desarrollo local

No requiere build. Abre `index.html` en el navegador o sirve la carpeta con cualquier servidor estático:

```bash
npx serve .
```

## Despliegue

Al ser un sitio estático puede publicarse directamente en GitHub Pages, Netlify, Vercel o cualquier hosting estático.
